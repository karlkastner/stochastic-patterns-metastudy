Source code accompanying the publication "A scale-invariant method for
quantifying the regularity of environmental spatial patterns", by Karl
Kästner et al, Ecological Complexity, 2024.

You can reproduce the analysis, tables and figures of the accompanying
manuscript by running the batch script "pattern_analysis_batch"

If you want to apply the method to you own patterns start from the script
"pattern_analysis_minimum_working_example", after fetching the dependencies.

Software requirements:
	Matlab (tested with version R2023b)

	The scripts accompanying the manuscript depend on library scripts. The
	library scripts are included in the pre-packaged archive available
	for download at Zenodo. You have to fetch the dependencies in case you
	downloaded the repository from github. You can fetch the dependencies
	automatically by running the script dependencies_fetch, or uncomment
	the respective line in the batch file "pattern_analysis_batch".

Data requirements:
	Extracted images of patterns from the references included in the meta-
	study. For copyright reasons, theses are not included in this
	repository but they can be requested by the first author, Karl Kästner.
